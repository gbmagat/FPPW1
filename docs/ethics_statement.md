# Ethics Statement

## Overview
This project focuses on PPE detection for workplace safety using computer vision.

## Risks
- Privacy concerns due to image monitoring
- Incorrect detections (false positives/negatives)
- Dataset bias from limited environments

## Mitigation
- No personal identification or facial recognition
- Confidence scores included in predictions
- Data augmentation applied to improve generalization
- System is used as a support tool, not a decision-maker

## Intended Use
The system is intended for safety monitoring and awareness, not for enforcement or disciplinary action.

## Limitations
- Limited dataset diversity
- May not generalize to all construction environments
